## 🔧 Требуется выполнить

### 1. Остановите сервер Django (Ctrl+C)

### 2. Установите зависимости:
```bash
cd backend
pip install -r requirements.txt
```

### 3. Пересоздайте базу данных:
```bash
del db.sqlite3
python manage.py migrate
python manage.py createsuperuser
```

### 4. Запустите сервер:
```bash
python manage.py runserver
```

### 5. Запустите React (в другом терминале):
```bash
npm start
```

## 📋 Использование новых функций

### Экспорт данных
1. Войдите в личный кабинет
2. Прокрутите до раздела "Экспорт данных"
3. Нажмите на нужный формат (Excel, Word, PDF)

### Загрузка файлов
1. В личном кабинете найдите раздел "Мои файлы"
2. Выберите файл через input
3. Файл автоматически загрузится
4. Для удаления нажмите 🗑️

### Уведомления
1. В шапке сайта появится иконка 🔔
2. При наличии непрочитанных - красный badge с числом
3. Клик по иконке открывает список уведомлений
4. Клик по уведомлению отмечает его прочитанным
